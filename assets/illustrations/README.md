# PREMIND illustration set

Original AI-generated product artwork for the PREMIND interface. The set uses
warm ivory, terracotta, peach, and sage clay forms to express recording,
transformation, and study completion without embedding text into imagery.

- `home-hero-hd.webp`: 2398×2624 microphone, notes, and time-memory motif
- `create-hero-hd.webp`: 3072×2048 recording transformed into a structured study pack
- `study-complete-hd.webp`: 2676×2352 completed learning pack and progress motif
- `audio-cover.webp`, `video-cover.webp`: compact 16:9 derivatives for cards

The HD WebP masters use two-times pixel density while staying smaller than the
original PNG exports. Cutout artwork preserves real alpha transparency so it
can sit on semantic theme surfaces. Keep informative labels in React Native
text, not in artwork, for localization and accessibility.
